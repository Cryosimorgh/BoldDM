# BoltDM v1.1

BoltDM v1.1 is the first public release.

## What it includes

- Go download manager for Windows.
- Chrome extension for collecting many similar download links from one page.
- Segmented downloads.
- Separate segment and connection settings.
- Pause, resume, retry, cancel, and remove controls.
- Pause all and resume all.
- Global speed limit with presets and a custom value.
- Change the default download folder.
- Move an in-progress download to another folder.
- Windows system tray with a full Exit command.
- Appearance settings for font, size, style, spacing, colors, corner size, reduced motion, and custom CSS.

## Windows note

The Windows executable is not signed with a trusted code-signing certificate. Windows SmartScreen can show an Unknown publisher warning.

The release includes `BoltDM.exe.sha256` so the executable can be checked after download.
